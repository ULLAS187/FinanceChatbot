# 💬 Personal Finance Chatbot

A Streamlit-based personal finance chatbot powered by IBM Granite 3.2 LLM.
It helps users with budgeting, savings, investing, and expense planning.

## Features
- AI-powered finance chatbot
- Monthly budget planner
- Expense visualization
- Local LLM inference (privacy-first)

## Tech Stack
- Python
- Streamlit
- IBM Granite 3.2
- PyTorch
- HuggingFace Transformers

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
